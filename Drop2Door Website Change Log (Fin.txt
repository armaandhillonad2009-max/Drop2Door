# Drop2Door Website: Change Log (Final Round)

How to navigate: all paths start from the project root `/app`. In the code editor's file tree, open `frontend`, then `src`, then the folder/file listed.

## 1. Hero outline font ("DELIVERED TO YOUR DOOR.")
- File: `frontend/src/pages/Home.jsx` (the Hero component, h1 block)

- File: `frontend/src/index.css`
  - Added two classes: `.text-outline-ice` (transparent fill + `-webkit-text-stroke: 1.5px` icy blue, used in the hero) and `.text-outline-faint` (1px faint stroke, used for the footer wordmark).

## 2. Mobile play icon overlapping the hero title (bug fix)
- File: `frontend/src/pages/Home.jsx`
  - Cause: on some phones (iPhone Low Power Mode blocks autoplay), the video element shows a big play glyph. Fix: the video now stays invisible until it is actually playing.
  - Added `const [vidPlaying, setVidPlaying] = useState(false);` in Hero.
  - On the `<motion.video>`: added `disablePictureInPicture`, `onPlaying={() => setVidPlaying(true)}`, and changed `animate={{ opacity: 0.5 }}` to `animate={{ opacity: vidPlaying ? 0.5 : 0 }}`.

## 3. FAQ section on Contact (now "Contact & FAQ")

  - Added the `Faq()` component (accordion rows: question + rotating plus icon, click to expand the answer with a smooth height animation) and rendered `<Faq />` under the contact section.

## 4. Footer
- File: `frontend/src/components/Footer.jsx`
  - Brand block: the phoenix circle + text stack was replaced with `<img src="/images/logo-dark.png" ...>` (the same logo image used in the top navbar).

## 5. Film strip scaling (3 bottles image before the delivery zone)
- File: `frontend/src/pages/Home.jsx` (the `FilmStrip()` component)
